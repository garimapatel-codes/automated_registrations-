About “one-time” links: WhatsApp does not offer single-use invite links, and a page that never touches the network can’t create them. To get the same effect, turn on Approve new participants in the group settings: anyone who taps the link only requests to join, and you approve only the people shown as Verified here. This app also records each invite as sent once, and asks before you send a second time.
